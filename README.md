# Tröööt

[![Modrinth Downloads](https://badges.moddingx.org/modrinth/downloads/trooot)](https://modrinth.com/project/trooot)
[![Modrinth Versions](https://badges.moddingx.org/modrinth/versions/trooot)](https://modrinth.com/project/trooot)

A simple mod that adds a loud fog horn that plays a sound when powered by redstone.

Why? I wanted a horn on my Valkyrien Skies ship. I suppose it might have other uses, maybe hide one deep underground below your "friend's" base and watch them spend ages finding it.
